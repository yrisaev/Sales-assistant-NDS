#  AI Ассистент менеджера НДС+

Внутренний инструмент для менеджеров B2B‑продаж (на примере продукта НДС+).

Приложение помогает:
- Быстро отрабатывать возражения клиентов
- Анализировать эффективность скриптов
- Вести статистику звонков
- Создавать личные и общие сценарии обработки

---

## Возможности

### Ассистент возражений
- Поиск возражений
- Топ популярных возражений
- Отработка для:
  -  Бухгалтера
  -  Директора
- Фиксация результата звонка

###  Гибридная архитектура (Shared + Private)
- Общие скрипты (методология команды)
- Личные скрипты (индивидуальный стиль менеджера)
- Приоритет личных сценариев над общими

###  Аналитика
- Количество отработок
- Конверсия в презентацию
- Конверсия в продажу
- Фильтрация по:
  - году
  - месяцу
  - диапазону дат
- Визуализация графиков

###  Управление базой знаний
- Редактирование скриптов
- Удаление возражений
- Разделение по пользователям

---

##  Архитектура

Приложение построено на:

- `Streamlit`
- `SQLite`
- Python 3.x

### Структура БД

**logs**
- objection
- client_type
- result
- timestamp

**scripts**
- objection
- client_type
- script
- question
- scope (shared / private)
- owner (username)

---

## 🔐 Авторизация

При запуске пользователь вводит имя.  
Скрипты делятся на:

- `shared` — общие для команды
- `private` — личные сценарии менеджера
